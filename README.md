# agentreadyvideo-site

Source for agentreadyvideo.org, the public home of the Agent-Ready Video (ARV) standard. Status: Draft 1.0, proposed. Maintained by AgentCDN.

- The standard itself (spec text, JSON Schemas, examples, conformance checklist, changelog, governance) lives in https://github.com/sandersaar/agentreadyvideo. `standard.lock.json` pins one commit of it. `node scripts/sync-standard.mjs` (`npm run sync`) downloads that commit as a GitHub tarball and extracts it into `vendor/standard/` (gitignored). No submodule and no git at build time. The sync fails if the SHA is missing or the download fails. To publish a new version of the standard, change the SHA in `standard.lock.json`.
- From that snapshot the build renders `/spec/1.0` (sections, numbered contents, conventions, key terms and section 6 from `CHANGELOG.md`), `/changelog` (`CHANGELOG.md`), the rules on `/governance` (`GOVERNANCE.md`), the standards table on the home page, the example tabs and quick start snippets, and serves `/schema/1.0/<name>.schema.json` (as `application/schema+json`) and `/examples/1.0/<name>.json`. `scripts/markdown.mjs` is the small Markdown converter; `scripts/standard.mjs` maps the repo's headings to the site's stable anchors.
- `src/pages/*.html`: page bodies. The first line is JSON front matter.
- `public/`: copied as is (styles, `site.js`, `llms.txt`, images). `site.js` only enhances: copy buttons, tabs, the spec contents and the theme toggle. Every page reads fine without it.
- `src/pages/*.html`: front matter needs `title`, `description`, `path`, `out`, and `crumb` on inner pages. `"schema": "techarticle"` (spec), `"schema": "faq"` (FAQ) and `"schema": "howto"` (quick start) add TechArticle, DefinedTermSet, FAQPage and HowTo JSON-LD, read from the page's glossary, Q&A sections and `step-*` headings. Macros: `{{example:name}}`, `{{spec:toc|conventions|glossary|sections|changes}}`, `{{standards-table}}`, `{{schema-table}}`, `{{changelog}}`, `{{governance:Section title}}`, `{{json:catalog|manifest-l1|video-jsonld}}`, `{{mid:call|id}}`, `{{std:repo|sha|short}}`, `{{tabs:id:a,b}}`, `{{code file="..." lang="..."}}...{{/code}}`, `{{cite}}`, `{{repo}}`.
- The spec lives at `/spec/1.0` (`src/pages/spec-1.0.html`). `/spec` redirects to the latest version and `/adopt` to `/quickstart` (`vercel.json`). A new version gets a new page and path; published versions never change.
- `npm run build` (sync, then `node build.mjs`): zero-dependency build into `dist/`. Vercel runs `node scripts/sync-standard.mjs && node build.mjs`. It writes per-page meta, Open Graph, Twitter and JSON-LD tags, `sitemap.xml` and `llms-full.txt`. It fails on em dashes, banned names, a missing title, description or canonical, a canonical that does not resolve to its file, more than one H1, skipped heading levels, a heading without an anchor link, duplicate ids, a broken internal link or fragment, missing links to spec, quick start, FAQ, implementations, governance or changelog, JSON-LD that does not parse, a page not listed in `llms.txt` and `sitemap.xml`, a schema whose `$id` is not its URL on this site, an example that does not parse or whose moment id does not recompute, a spec contents entry whose section is missing, or a `vercel.json` without the schema content type.
- `node scripts/serve.mjs [port]`: zero-dependency preview of `dist/` that applies the `vercel.json` redirects, clean URLs and headers.
- `node scripts/og-image.mjs`: redraws `public/og.svg` and renders `public/og.png` (1200x630) with local Chrome. Run it by hand when the card text changes.

Deploys on Vercel (`vercel.json`). Licenses: spec text Community Specification License 1.0, code Apache-2.0, docs CC-BY-4.0.
