Adopt ARV

You do not need to learn thirteen specs. Read one manifest format, run one validator, and copy one starter.

1. Pick a level

LevelWhat you publishWho it suits
L1 crawl-readable/.well-known/arv, a catalog at /arv.json, JSON-LD Clips on video pages, a sitemap, llms.txt, and an RSL license fileAny site, including a static one. No server code.
L2 agent-callableL1 plus an MCP endpoint with the origin profile, playback through short-lived tokens, and no stream URLs in any discovery responsePublishers who want agents to search and play their moments directly
L3 rights and ledgerL2 plus published keys, signed playback tokens, signed usage receipts, and rights that hold under negative testsPublishers who license video and need proof of use

Nobody has to implement rights or receipts to be listed. Start at L1 and move up when it pays. The full checks are in spec section 5.

2. Check it with the validator coming

The validator is a command-line tool and a hosted page. It runs all 18 checks against a live origin or a local folder and prints pass or fail per standard.

A green run earns the badge for that level, with a dated report URL. Reports expire after 90 days unless you run the validator again. Until the validator ships, check your objects by hand against the examples.

3. Start from a starter

L1

Reference producer coming

Give it a transcript and chapters. It writes a static L1 site: manifest, catalog, JSON-LD, sitemap and llms.txt. No network calls.

Playback

Player adapter coming

Under 100 lines per player. Reads a PlaybackDescriptor and starts at start_ms, with optional cue points. It never cuts the viewer off at the end.

L2

MCP origin profile coming

Five tools with fixed names: search_moments, get_moment, get_rights, play_moment, record_usage. Discovery never returns a stream URL.

What you can do today

  1. Read the spec.
  2. Copy the manifest and catalog examples and fill them with your own videos.
  3. Name each moment arv:{asset_id}#t={start_ms},{end_ms} and use the same URI as the Clip @id in your JSON-LD.
  4. Tell us what broke or was unclear: team@agentreadyvideo.org.
