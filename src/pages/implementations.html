The AgentCDN origin is self-declared and has not yet passed the validator, because the validator is not released. No outside implementation is listed, because none exists yet. The draft stays "proposed" until an outside implementation passes the validator. See how a feature becomes required.

What counts as an implementation

  • Origin. A site or platform that publishes ARV at L1, L2 or L3.
  • Producer. A tool that writes ARV files or endpoints for someone else's video.
  • Agent or client. An assistant or library that reads ARV and cites or plays moments.
  • Player adapter. Code that starts a player from a PlaybackDescriptor.

An entry needs a public URL and, once the validator ships, a current validator report for the level it claims. Until then we list entries as "self-reported".
