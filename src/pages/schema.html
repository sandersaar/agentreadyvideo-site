Schema 1.0

Seven objects make up ARV 1.0. Each has a JSON Schema and an example.

Each schema is JSON Schema draft 2020-12, served as application/schema+json at a fixed URL, and its $id equals that URL. Published versions never change; a new version gets a new path. The schemas and examples below come from the source repository at commit {{std:short}} and match the spec text.

Rules for every object

  • Every object carries "arv": "1.0".
  • Times are integer milliseconds.
  • Moments are named arv:{asset_id}#t={start_ms},{end_ms}.
  • Vendor data lives under extensions with a reverse-domain key.
  • Schemas and examples are served with Access-Control-Allow-Origin: *, so you can fetch them from a browser or test.
