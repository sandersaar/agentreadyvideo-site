Schema 1.0

Seven objects make up ARV 1.0. Each has a JSON Schema and an example.

The schema files are not published yet. When they are, each lives at a fixed URL, and its $id equals that URL. Published versions never change; a new version gets a new path. Until then, the examples below are served as JSON and match the spec text.

Rules for every object

  • Every object carries "arv": "1.0".
  • Times are integer milliseconds.
  • Moments are named arv:{asset_id}#t={start_ms},{end_ms}.
  • Vendor data lives under extensions with a reverse-domain key.
  • Examples are served with Access-Control-Allow-Origin: *, so you can fetch them from a browser or test.
